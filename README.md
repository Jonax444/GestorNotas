# Gestor de Notas Académicas

## Redacción del Problema

El **Gestor de Notas Académicas** está diseñado para ayudar a los estudiantes a organizar y manejar sus calificaciones de forma sencilla desde la consola.

La idea principal es que el estudiante pueda registrar sus cursos con las notas correspondientes, y también tenga la opción de verlas, modificarlas o eliminarlas fácilmente.  
Además, el sistema permite realizar análisis básicos, como calcular el promedio general y saber cuántos cursos han sido aprobados o reprobados.

Este programa es útil porque, al estar basado en consola y contar con un menú interactivo, permite al estudiante controlar su información académica sin complicaciones, utilizando estructuras simples que facilitan la organización, búsqueda y manejo de la información.

---

## Requisitos del Sistema

### Requisitos Funcionales
- Registrar un nuevo curso con su respectiva nota.  
- Mostrar todos los cursos y sus notas registradas.  
- Calcular el promedio general de las notas ingresadas.  
- Contar cuántos cursos han sido aprobados y reprobados.  
- Buscar un curso por nombre usando búsqueda lineal.  
- Actualizar la nota de un curso existente.  
- Eliminar un curso del registro.  
- Ordenar los cursos por nota (usando ordenamiento burbuja).  
- Ordenar los cursos por nombre (usando ordenamiento por inserción).  
- Buscar un curso por nombre usando búsqueda binaria.  
- Simular una cola de solicitudes de revisión de notas.  
- Mostrar un historial de cambios usando una pila.  

### Requisitos No Funcionales
- El programa se ejecuta en consola usando Python.  
- No se utilizan librerías externas, solo funciones estándar.  
- Debe incluir al menos una estructura repetitiva para mostrar el menú principal.  
- El código está organizado en funciones para mantener claridad y orden.  
- Se aplican validaciones básicas, por ejemplo, que las notas estén entre 0 y 100.  
- Se utilizan estructuras de datos como listas, pilas y colas, junto con algoritmos de búsqueda y ordenamiento.

## Reflexión Personal

### 1. ¿Qué aprendí con este proyecto?
Con este proyecto aprendí a organizar mejor la información y a aplicar lo que sé de programación en una situación práctica.  
Pude practicar cómo crear un programa con varias opciones, validar los datos que ingresa el usuario y mostrar los resultados de forma clara.  
También entendí mejor cómo funcionan las búsquedas y los distintos modos de ordenar información dentro de un programa.

### 2. ¿Qué fue lo más desafiante de resolver?
Lo más desafiante fue lograr que todas las funciones trabajaran bien entre sí y que el programa no tuviera errores.  
También fue un reto hacer que el menú fuera fácil de usar y comprensible para el usuario.  
Tuve que revisar varias veces el código para asegurarme de que cada parte cumpliera correctamente su función.

### 3. ¿Qué mejoraría si tuviera más tiempo?
Si tuviera más tiempo, mejoraría la presentación del programa para que se viera más atractiva y ordenada.  
También me gustaría agregar la opción de guardar los datos para no perder la información al cerrar el programa.  
Además, intentaría hacerlo más completo, añadiendo nuevas funciones que hagan el sistema aún más útil para los estudiantes.
